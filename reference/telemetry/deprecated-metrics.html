(Deprecated) Prometheus metrics reference

These Prometheus-style metrics are deprecated and will be removed in a future release. They are retained here for reference only. New deployments should use the OpenTelemetry-based metrics documented in the metrics reference.

Akka collects metrics for monitoring the runtime behavior of your services.

These metrics are available for export to external monitoring systems.
